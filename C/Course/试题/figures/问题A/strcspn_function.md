`strcspn` 是 C 标准库中的一个函数，用于在字符串中查找第一个匹配字符的位置。其函数原型如下：

```c
size_t strcspn(const char *str1, const char *str2);
```

具体来说，`strcspn` 计算字符串 `str1` 中第一个出现在字符串 `str2` 中的字符之前的字符数（即从字符串开头到第一个匹配字符的距离）。如果 `str1` 中没有任何字符出现在 `str2` 中，则返回 `str1` 的长度。

在上面的代码中：

```c
input[strcspn(input, "\n")] = 0; // 去除字符串末尾的换行符
```

`strcspn(input, "\n")` 查找字符串 `input` 中第一个换行符 `\n` 的位置，并将该位置的字符替换为 `\0`，从而去除输入字符串末尾的换行符。

例如：

```c
char input[] = "123\n";
input[strcspn(input, "\n")] = 0;
```

执行上述代码后，`input` 将变成 `"123"`，即去除了末尾的换行符。这对于处理从标准输入读取的字符串特别有用，因为标准输入通常会包含换行符。

总结：

- `strcspn` 用于查找指定字符在字符串中的位置。
- 在这个示例中，它被用来去除输入字符串末尾的换行符，以便后续处理。
